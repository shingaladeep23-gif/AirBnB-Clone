Decisions worth defending

1 · Overlays are URL state

Both overlays live in search params, not useState. That is what makes them deep-linkable, reload-safe and Back-navigable — matching behaviour, not just appearance. The brief grades behavioural parity explicitly.

2 · Measure the rendering, never the source

The copy checker reads the rendered page. Reading strings out of lib/listing.ts would mean re-implementing JS escape semantics — which is the exact layer the bug hides in.

3 · Numbers or PENDING, never prose

"Rounded corners" with no value is not a specification, it is an invitation to guess. One such gap produced an 18px radius where the reference uses 12px on a single clipping wrapper.

4 · A gate that can skip is worse than no gate

The copy checker's first version went green whenever it could not reach a page — inside a script that never starts a server. It would have read as coverage forever. Exactly one skip condition is now allowed, and it is explicit.

5 · Fonts are unobservable

fontFamily returns the declared stack, never the resolved face, and document.fonts.check() returns true for a font that never loaded. A whole pass of widths was taken against Segoe metrics before the tell was found: height exact + width wrong = glyphs, not CSS.

6 · Disclosure is a holding position

While the channel was blocked, invented copy was isolated in one module and disclosed. That constraint is what later made replacing it with measured strings a data edit rather than a rewrite.

7 · Shared state is not just files

Single-writer file ownership broke three times — on a shared type, a shared .next directory, and the shared git index. Whoever changes a shared thing owns every consumer of it in the same commit.
