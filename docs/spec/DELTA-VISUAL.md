## How to read this

Two browser renders of identical CSS are never bit-identical, so a raw pixel diff is worthless. Every differing pixel here is classified: **edge-shift** (the same colour exists within one pixel in the other image — anti-aliasing, hinting, sub-pixel text placement) or **structural** (nothing like it nearby — something is in a different place, a different colour, or absent). Ranking is by structural pixels only. Per-pixel tolerance is YIQ distance > 0.1; a region is a finding at >= 0.5% structural of its own area and > 200 px.

A large edge-shift count with near-zero structural is itself a result: same shapes, different glyph rasterisation. That is a typography question, not a layout one.
